A code change that can be executed, built or type-checked gets a real check that exercises it before it is called done: the project's test suite, its type checker or its build, or a run of the changed command. Checking only the syntax does not count, and neither does a check command that never started. If all that is lacking is the dependencies the project declares, install those with the project's own package manager and lockfile (npm install, or pip install -r requirements.txt, for example), not with sudo or the system's package manager, unless the user said not to. Only when no real check is possible here does the report say which check was skipped and why, in place of calling the change done.
