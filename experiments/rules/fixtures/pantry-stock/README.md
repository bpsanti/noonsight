# pantry-stock

The stock of a food bank's pantry, from a plain-text stock file (see `data/stock.txt`), on the command line.

## Commands

### `list <file>`

Prints every batch in the stock file, one per line: name, category, quantity, unit and the day it expires.

### `report <file>`

Prints the total of each category.

## Development

Run the tests with `npm test`.
